## F1 / F2 / F3 已实施结构与结果

本节从实际代码、`metrics.jsonl`、`validation_selection.json` 和逐图 `metrics.csv` 核对。五组主结果均采用验证集选择的 `best_metrics.pth`；八项测试均值按 361 条逐图记录重新计算，排除 CSV 的 `MEAN` 行。F1/F2/F3 各有完整 1–100 轮日志，两种选优权重各有 361 张融合图和评估完成记录。

### 与 E1 的网络区别

| 部分 | E1 | F1 | F2 |
|---|---|---|---|
| L1 | CSP → 原 `fuse1` | 相同 | 相同 |
| L2 `fuse2` | 拼接 → 1×1 卷积 → GELU → 3×3 卷积 | 独立分频 → 低频差分通道交互、高频轻量卷积 → 合并 | 同 F1，差分改为预测残差 |
| 分频 | 无 | 两模态独立 LearnableFDM，3×3 核、8 组 | 相同 |
| 低频交互 | 无独立分支 | 4 头双向通道交叉注意力 | 相同 |
| 预测器 | 无 | 无 | 两个独立 64→96 投影、32 通道双尺度上下文预测器 |
| L3/L4、decoder | 原网络 | 相同；不增加 RFGM | 相同 |
| 附加损失 | 无 | 无 | 双向预测 MSE，系数 1 |
| `fuse2` 参数量 | 45,184 | 66,792 | 83,752 |

实现位于 [dual_band_fusion.py](fusion/models/dual_band_fusion.py)。FDM 根据单源特征的全局池化结果生成可学习的非负归一化核，用动态深度卷积实现局部平滑，避免显式 `unfold` 展开。低频为滤波结果，高频为输入减低频，两者相加恢复输入。这是可学习局部平滑/细节分解，不是严格频率截止的 FFT 分解。

记可见光/红外低频为 A/B，sg 为停止梯度。两个方向使用原始单源特征并行计算：

```text
F1：E_I = B - sg(A)；E_V = A - sg(B)
F2：pred_I = P_VI(sg(A))；pred_V = P_IV(sg(B))
    E_I = B - sg(pred_I)；E_V = A - sg(pred_V)

U_A = CA_V(A, E_I)；U_B = CA_I(B, E_V)
CA(Q源, 消息) = reshape[softmax(τ × normalize(Q) × normalize(K)^T) × V]
Q 来自当前模态，K/V 来自消息；归一化沿空间维，每头注意力矩阵为 16×16。

F_L = GELU(Conv1×1(cat(A, B, U_A, U_B)))
F_H = GELU(DWConv3×3(GELU(Conv1×1(cat(A_H, B_H)))))
fuse2_output = Conv1×1(F_L + F_H)
```

注意力内部没有 `project_out`，由 `low_fuse` 统一投影；保留最终输出投影。新融合模块直接输出新特征，没有小残差缩放、旧 `fuse2` 并行路径，也没有 CMA、独立 FFN、AFM。F2 当前预测器仍为**并行**局部 DW3 与空洞 DW3(d=2)，尚未改为 `wide(z2 + u1)`。两个预测器各 8,480 个权重，初始为恒等映射；融合损失不更新预测器，预测损失不更新编码器。

### 展示哪些指标，以及如何解释

建议主表用 **QABF、VIF、MI、SSIM**；空间允许再加 **SF**。前三项体现当前最明确的收益，SSIM 保留结构相似性代价，SF 补充纹理活动。完整八项放补充材料并保持所有方法同一指标集合，不在看到测试结果后反复换指标或改验证选优规则。

| 指标 | 主要含义 | 与模块的合理联系及边界 |
|---|---|---|
| QABF | 源图边缘强度/方向的传递质量 | 高频细节分支与低频互补交互可能改善边缘保留；需要分支消融才能归因 |
| VIF | 与源图相关的视觉信息保真 | 双向交互可能保留更多可用源信息；不等于下游检测一定改善 |
| MI | 融合图与两源图的统计信息关联 | 可用于检验互补信息保留；高 MI 本身不能证明残差语义有用或无噪声 |
| SSIM | 与双源的结构相似性（本实现求和） | F1/F2 略降必须报告，体现信息保留与结构相似度的权衡 |
| SF | 空间变化/纹理活动 | 分频后细节保留的辅助证据；噪声和过锐化也可能推高 SF |

EN/SD/AG 仍报告，但不宜单凭增大就认定融合质量更好。当前结论是“边缘和信息保持改善，结构相似性略有代价”，不能声称所有质量维度提升。F1/F2 相对历史 E1 的结构归因还受额外 100 轮训练影响，需要同预算 E1 继续训练对照。

### 预测残差是否有效：结果与实测诊断

F2（80）相对 F1（100）的绝对变化为：EN −0.001093、SD +0.015544、SF −0.011602、MI +0.012099、VIF −0.000490、QABF +0.000989、AG −0.005996、SSIM −0.000028。只提高 SD/MI/QABF 三项，MI 和 QABF 的相对增益分别约 0.3645% 和 0.1390%。这是同一选优规则下的结果，不是同 epoch 比较；两者第 100 轮比较时，F2 的 MI/VIF/QABF 都略低于 F1。不能据此声称预测残差稳定全面胜过直接差分。

训练日志中 F2 预测 MSE 从第 1 轮 0.154323 降至第 80 轮 0.050077、第 100 轮 0.048637，但目标特征随主网络变化，单看下降不足以判断优于恒等预测。

为核实机制，本次用 F2 `best_metrics.pth`（epoch 80）对**固定 108 张原分辨率验证图**补做只读诊断，复用现有 forward 中的低频和预测结果，未训练、未改模型或权重。按整个子集累积 SSE 后计算，未平均逐图比率：

```text
G_VI = 1 - sum(||B - P_VI(A)||²) / sum(||B - A||²)
G_IV = 1 - sum(||A - P_IV(B)||²) / sum(||A - B||²)
```

| 验证子集 | 恒等预测 MSE | V→I 预测 MSE | I→V 预测 MSE | G_VI | G_IV |
|---|---:|---:|---:|---:|---:|
| all（108） | 0.109157 | 0.016010 | 0.034106 | 85.3328% | 68.7554% |
| day（53） | 0.121371 | 0.016847 | 0.035704 | 86.1190% | 70.5826% |
| night（55） | 0.097388 | 0.015204 | 0.032565 | 84.3886% | 66.5611% |

all 累计 530,841,600 个单向目标特征元素；所有分母非零。权重 SHA256：`fdf60d1745be89d02d9ebc6f2c686b07c0a5f848668cd78a1394bca439277ebd`。这些是事后验证诊断，当前训练日志没有自动记录 G。

这证明两个预测器已经学习到优于恒等映射的跨模态预测，且白天/夜晚均成立。G 是相对预测误差改善，不能用作置信度；它也不能证明融合网络充分利用了预测残差。F2 的剩余消息能量更小，仍有价值的模态信息可能被预测掉；融合网络也能通过原低频直连绕过注意力消息，因此“预测更准确”与“融合更优秀”需要分别验证。

下一步按成本排序：

1. 先固定 F2 权重，在验证集把预测器输出临时替换为恒等预测，再分别关闭一个方向的注意力消息；比较 QABF/VIF/MI/SSIM 与正常输出。这是无需重训的敏感性诊断，存在分布变化，不能代替训练消融。
2. 为机制归因补 E1 同预算继续训练对照；F1/F2 小差距需多 seed 或逐图配对置信区间验证，不能只数涨了几项。
3. 保留 MSE、三个 detach 及主网络/预测器分别裁剪，先自动记录双向 G、双向 MSE、残差/恒等差分能量比。不要只提高预测损失系数；梯度隔离且存在裁剪时，这主要改变预测器更新，不会直接修复 SSIM。
4. 只做一个低成本预测器变体：`u1=GELU(local(z1)); u2=GELU(wide(z2+u1)); P=M+out(cat(u1,u2))`。仍为每方向 8,480 个权重，双方向只多 `32×B×H2×W2` 次相加；不增加门控或输出缩放。此变体必须新目录重新训练，不能对现有 F2 权重静默改 forward 后当原实验续跑。
5. 若误差分布显示少数大异常主导，再单独比较 Smooth L1/Charbonnier 与 MSE；若两方向/通道尺度长期失衡，再考虑停止梯度的目标方差归一化并设稳定下限。每次只改一个变量。稳健损失改变预测目标，归一化改变误差权重，均不能预先保证融合涨点。暂不增加不确定性头、循环一致性或残差压零损失。

## F3：预测残差 K＋辅助原低频 V

F3 只检验一项机制：预测残差是否更适合建立通道关系，而完整辅助低频是否更适合承载被传递的内容。FDM、并行双尺度预测器、预测 MSE、高频分支、低频汇合与输出投影全部沿用 F2；没有加入层级预测器、结构预测损失、门控、FFN 或额外参数。

记可见光、红外低频为 A、B，sg 为停止梯度：

```text
pred_I = P_VI(sg(A))                 pred_V = P_IV(sg(B))
R_I = B - sg(pred_I)                 R_V = A - sg(pred_V)

F2: U_A = CA(Q=A, K=R_I, V=R_I)     U_B = CA(Q=B, K=R_V, V=R_V)
F3: U_A = CA(Q=A, K=R_I, V=B)       U_B = CA(Q=B, K=R_V, V=A)
```

F3 的 `value_source` 不停止梯度，融合损失可以更新提供 V 的单源编码特征。预测结果进入消息前仍停止梯度，所以融合损失不更新预测器；预测目标和输入仍停止梯度，所以预测 MSE 只更新两个预测器。

[dual_band_fusion.py](fusion/models/dual_band_fusion.py) 为 `ChannelCrossAttention.forward` 增加可选 `value_source`。默认值为 `None`，F1/F2 完整保留原联合 KV 路径。F3 复用同一个 `kv.weight`：前 C 个输出通道投影残差 K，后 C 个输出通道投影原低频 V，拼接后只调用一次原深度卷积。该设计没有新增参数或主要理论卷积 MAC，也没有复制注意力模块。它是残差引导的全局通道关系，不是逐像素置信度或可靠性门控。

F2/F3 的 `fuse2` 均为 83,752 个参数，每个预测器均为 8,480 个参数。相同 seed、相同 E1 权重下，两者 601 个 state-dict 项逐项相同，区别只来自 V 的输入。新模型使用独立注册名、配置和目录；即使 state-dict 形状相同，也不能交叉恢复。训练入口会检查 resume checkpoint 的完整配置。

正式训练和 361 张测试集评估已经完成。F3 的 `best_metrics.pth` 与 `best_loss.pth` 都选中 epoch 100，并得到相同结果。相对 F2 的验证选优主结果，F3 的变化如下：

| F3 − F2 | EN | SD | SF | MI | VIF | QABF | AG | SSIM |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| 绝对变化 | +0.000829 | −0.008616 | +0.013130 | −0.019428 | −0.000059 | −0.001292 | +0.006964 | +0.000188 |
| 相对变化 | +0.0124% | −0.0202% | +0.1170% | −0.5832% | −0.0055% | −0.1814% | +0.1351% | +0.0135% |

F3 和 F2 各提高四项，但不能按数量判为相同：F3 的提升集中在纹理活动与轻微结构相似度，F2 保住了更关键的 MI/QABF，VIF 也略高。再比较同为 epoch 100 的补充权重时，F2 在 EN、SD、SF、MI、VIF、QABF 六项更高，F3 只在 AG、SSIM 略高，因此当前应保留 F2 为主方案，把 F3 作为“残差 K＋完整源 V 未形成收益”的受控消融。
